# Промпт для импорта в OpenCode

Скопируй текст ниже целиком в OpenCode, предварительно заменив путь к пакету.

---

Ты устанавливаешь агентную схему работы с уже подключённым `agent_memory` MCP.

Распакованный пакет находится здесь:

`<ABSOLUTE_PATH_TO_UNPACKED_PACKAGE>`

Сам MCP уже развёрнут и настроен. Не разворачивай сервер, не меняй SSH, не
редактируй `opencode.json`, не добавляй MCP server и не запрашивай credentials.

Нужно установить только:

- глобальный блок правил памяти;
- subagent `agent-memory-reviewer`;
- команды `/memory-review` и `/memory-status`.

Работай до проверенного результата, сохраняя все несвязанные пользовательские
настройки.

## 1. Предварительный аудит

1. Определи фактический home пользователя, под которым работает OpenCode. Если
   OpenCode запущен в WSL, используй Linux home внутри WSL.
2. Прочитай `README.md`, `global/AGENTS.md`, agent и обе команды из пакета.
3. Убедись, что пакет не содержит `opencode.json`, SSH config, private keys,
   токены, пароли или API keys.
4. Не меняй текущую конфигурацию MCP. Выполни только read-only проверку доступных
   MCP servers/tools средствами уже установленного OpenCode.
5. Если `agent_memory` сейчас не виден, сообщи точный результат и остановись: не
   пытайся самостоятельно перенастраивать MCP.

## 2. Установи глобальные правила

Целевой файл: `~/.config/opencode/AGENTS.md`.

1. Возьми блок между `BEGIN AGENT_MEMORY_POLICY` и
   `END AGENT_MEMORY_POLICY` из `global/AGENTS.md`.
2. Если целевой файл отсутствует, создай его из шаблона.
3. Если файл существует:
   - создай рядом timestamped backup;
   - замени только существующий блок с теми же маркерами;
   - если блока нет, добавь его в конец;
   - сохрани все другие правила без изменений.
4. Не записывай в `AGENTS.md` содержимое памяти, проектные факты или credentials.

## 3. Установи subagent и команды

Создай каталоги при необходимости и установи:

- `agents/agent-memory-reviewer.md` ->
  `~/.config/opencode/agents/agent-memory-reviewer.md`
- `commands/memory-review.md` ->
  `~/.config/opencode/commands/memory-review.md`
- `commands/memory-status.md` ->
  `~/.config/opencode/commands/memory-status.md`

Для каждого существующего одноимённого файла:

1. Создай timestamped backup.
2. Покажи краткое содержательное сравнение.
3. Если существующий файл содержит дополнительные пользовательские правила,
   объедини их или запроси подтверждение, а не затирай молча.

Не редактируй никакие другие agents или commands.

## 4. Проверь обнаружение файлов

1. Подтверди, что итоговый глобальный `AGENTS.md` содержит ровно один блок между
   маркерами memory policy.
2. Подтверди, что OpenCode обнаруживает subagent
   `@agent-memory-reviewer`.
3. Подтверди наличие `/memory-review` и `/memory-status`.
4. Не вызывай write-операции памяти в качестве теста.
5. Если текущая сессия не перечитывает глобальные файлы динамически, попроси меня
   перезапустить OpenCode и затем вставить `VERIFY_PROMPT.md`.

## 5. Финальный отчёт

Сообщи:

- какие файлы созданы или обновлены;
- где лежат backups;
- доступен ли существующий `agent_memory` MCP;
- обнаружены ли subagent и команды;
- требуется ли перезапуск;
- остались ли конфликты с существующими пользовательскими правилами.

Не говори, что установка завершена, если MCP недоступен или новые файлы не
обнаружены. Не пытайся исправлять MCP без отдельного запроса.
